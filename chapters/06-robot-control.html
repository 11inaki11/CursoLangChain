Mission control

Everything together: give R-80 a goal in plain English and it plans, checks the manuals, reads its sensors and moves, live.

StreamingAll toolsHuman in the loop

// THE CONCEPT

The agent turns a goal in natural language into a sequence of tool calls, adapting the plan to what its sensors and manuals say. Streaming lets you watch every decision live, and human-in-the-loop pauses before risky actions.

// YOUR ROBOT GAINS

  • Missions described in plain English
  • Plans that adapt to battery, rules and errors
  • A human veto on dangerous actions

// KEY TERMS

  • Streaming: receive each step as it happens
  • interrupt(): pause the graph for a human
  • Orchestration: LLM plans, classic code executes

The simulator

An 8×6 lab, five stations and three items. R-80 knows only what its tools tell it. Try the three missions: a normal one, one with low battery (the manual changes the plan), and one that needs a human's approval.

The code

Same agent as chapter 2, plus memory and stream(), so you see every tool call the moment it happens instead of waiting for the end.

if __name__ == "__main__":
    WORLD.add_robot("r80")
    agent = create_agent(
        model=get_model(),
        tools=make_robot_tools("r80") + [build_manual_tool()],
        system_prompt=SYSTEM_PROMPT,
        checkpointer=InMemorySaver(),
    )
    config = {"configurable": {"thread_id": "mission-control"}}
    print(WORLD.render())

From the simulator to a real robot

Swap WORLD.move_to() for a ROS 2 action, an HTTP call to your robot's API or a serial command. The agent doesn't care: it only sees the tool's name, docstring and result string.

Keep the LLM out of the fast loop. Let it plan and orchestrate (seconds). Keep low-level control, like motor loops and obstacle avoidance, in classic real-time code (milliseconds).
