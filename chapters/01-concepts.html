What is LangChain / LangGraph?

One idea to remember: everything is a node. The model, the tools, the memory, the human and other agents are pieces you plug together.

ConceptsNo code

// THE CONCEPT

An LLM alone only produces text. An agent wraps it in a loop: think → act with a tool → observe the result → think again, until the goal is done. LangChain gives you the pieces. LangGraph wires them together.

// KEY TERMS

  • Agent: LLM + tools + a loop

  • Graph: nodes connected by edges

LangChain vs LangGraph

LangChain

High-level building blocks: chat models behind one interface, tools, retrievers, messages, and create_agent(), a ready-made agent loop. Start here.

LangGraph

The low-level engine underneath: you draw the graph yourself with nodes, edges, shared state, cycles and checkpoints. Use it when one agent loop is not enough.

create_agent() is a LangGraph graph. Everything you learn in chapters 2–4 still applies when you build custom graphs in chapter 5.

Why a framework at all?

Raw APIs

Full control, but you rewrite the tool loop, retries, memory and provider quirks for every project. Too low-level.

LangChain + LangGraph

The middle ground: reusable pieces, any model, and you still own the code and the control flow.

n8n / no-code

Fast to click together, but hard to version, test, debug or run inside a robot's stack. You lose control.
