Boot sequence

Ten minutes to get the lab running: Python, one LLM provider of your choice, and a robot that already moves without any AI.

Python 3.10+1 API key (or local)

// THE CONCEPT

An agent needs three things to run: code, a model provider (whoever runs the LLM) and a world to act on. Here we set up all three.

// YOUR ROBOT GAINS

  • A Python environment with LangChain + LangGraph
  • Access to an LLM: cloud API or your own GPU
  • Lab 80: a simulated world to control

// KEY TERMS

  • Provider: company or server that runs the LLM
  • API key: your password to a cloud provider
  • .env: local file that keeps keys out of your code

Get the code

git clone https://github.com/11inaki11/CursoLangChain.git
cd CursoLangChain/code
python -m venv .venv && source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt
⬇ Download all code (.zip) requirements.txt .env.example

Choose your provider

Any of these works for the whole course. Pick one, get the key, and put the two lines in code/.env (copy .env.example first). Your choice is remembered, and chapter 2 will show the same provider.

Install
ollama.com ↗ then ollama pull qwen3:8b
Package
pip install langchain-ollama
Model string
ollama:qwen3:8b
Notes
No key and no per-call cost: runs on your laptop or your own GPU server. Pick a model with good tool calling.
ROBOT_MODEL=ollama:qwen3:8b
OLLAMA_BASE_URL=http://localhost:11434
# Model on a remote GPU box? Tunnel its port to your laptop:
ssh -N -L 11434:localhost:11434 user@gpu-server

Never commit your .env. It's already in .gitignore. Treat API keys like passwords: they are billed to you.

Meet the lab (no AI yet)

robot_world.py is the "hardware": a pure-Python lab with five stations, three items and robots that burn 2% battery per grid step. Every chapter controls this same world.

"""
robot_world.py — a tiny, dependency-free robot lab.

This is the "hardware" every chapter talks to. There is no LLM here: just
plain Python that keeps track of where the robots are, what they carry and
how much battery they have left. The agents in later chapters control it
through tools.

$ python robot_world.py
r80 arrived at shelf_a after 7 steps. Battery: 86%.
r80 picked up red_cube.
r80 arrived at workbench after 7 steps. Battery: 72%.
r80 placed red_cube at workbench.

No LLM yet. These are plain function calls that you ordered. In chapter 2 we hand the same functions to an LLM and let it decide which to call.
